4. PERSISTENT DOCUMENT INDEX
==================================================

The current implementation creates an index in memory.

Fix this.

When a PDF is first opened/indexed:

1. Extract text.
2. Build chunks.
3. Generate embeddings.
4. Build lexical/full-text index.
5. Store the complete index persistently.

When the same PDF is opened again:

1. Determine whether the PDF has changed.
2. If unchanged, load the existing index.
3. Do NOT re-extract and re-embed the entire PDF.

The cache/index identity should account for document changes.

Use an appropriate document fingerprint based on things such as:

- absolute path
- file size
- last modified time
- and/or a cryptographic hash if appropriate

Do not trust only the filename.

5. CHUNK METADATA — VERY IMPORTANT
==================================================

The current implementation loses too much information about where a chunk came from.

Fix this.

Every chunk MUST retain enough information to identify its exact original PDF location.

A chunk should conceptually contain:

ChunkId
PageIndex

Text

The relationship between:

TEXT → WORDS → PAGE → PDF COORDINATES

must be preserved.

The chunk can still be treated as one retrieval unit, but its source-location metadata must preserve each page separately.

For citations, prefer returning individual page-level source records.

8. HYBRID SEARCH
==================================================

Implement BOTH:

A. Lexical retrieval
B. Semantic retrieval

Lexical retrieval should support exact terminology.

Semantic retrieval should support conceptual questions.

Example:

"provincial taxation administration"

User asks:

"How did the government collect revenue in its provinces?"

Semantic retrieval should still identify the relevant passage even though the wording differs.

Conversely, if the user searches for:

"Blanchard 2001"

exact lexical retrieval should work extremely well.

Combine the results.

Do not simply concatenate the two lists.

Normalize scores and implement a sensible hybrid ranking.
